# news-image-20261124

A newspaper front page summing up Tuesday 24 November 2026: a Brooklyn jury convicts Huawei on 10 of 12 counts, Nvidia brings back Jensen Huang as chief executive, a Houthi strike hits a Riyadh tower injuring 11, Ukraine hits Russian ships in the Gulf of Finland and off Libya, a Turkish military helicopter crash kills five, and Senegal win back the Africa Cup title.

## About

The image is a clean 1024x1024 front page drawn with Pillow: masthead, date, and six verified stories from 24 November 2026, each with a bold headline and a one-sentence summary. `main.py` is a Python 3 standard-library-only program that validates `entry.png` (a whole PNG, at most 1,048,576 bytes, exactly 1024x1024) and copies it to `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.png`. It runs with no network and writes the same bytes on every run.
